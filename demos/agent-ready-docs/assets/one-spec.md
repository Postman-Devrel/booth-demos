# One spec → everything

Full-screen this file in Act 5. Every URL below is real and was verified live;
open any of them if someone doubts a link in the chain.

```
                    ONE OpenAPI SPEC
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
        ▼                  ▼                  ▼
   ┌─────────┐      ┌─────────────┐    ┌──────────────┐
   │  SDKs   │      │   PORTAL    │    │ AGENT SURFACE│
   └─────────┘      └─────────────┘    └──────────────┘
        │                  │                  │
   elevenlabs-js      elevenlabs.io/docs   /llms.txt
   elevenlabs-python  guides + reference   <page>.md
   + 6 more languages playground, search   /openapi.json
                      changelog, AI chat   /.well-known/api-catalog
                                           /_mcp/server
```

Everything on the right regenerates on every docs build. Nothing on the right is
hand-maintained. That is the entire argument.

## The chain, with live URLs

| Artifact | URL | What it proves |
|---|---|---|
| Agent index | <https://elevenlabs.io/docs/llms.txt> | Every page, one fetch, always current |

| On npm | `npm i @elevenlabs/elevenlabs-js` | v2.60.0 — real package people install |

> **Note.** ElevenLabs' own `api-catalog` is empty and its `openapi.json` is
> auth-gated, which is why it scores 90 rather than 100 and why Act 5 uses
> Cohere for the api-catalog demonstration. Do not fake this — the fact that the
> scorecard docks a Fern customer 10 points is the reason anyone believes it.
