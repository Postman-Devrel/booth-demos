No Spec

Most APIs lack an OpenAPI spec. Agents can't discover what they can't see.

⚠

Poor Errors

Vague error messages leave agents guessing. They need structured, actionable responses.

🔒

Complex Auth

Multi-step auth flows break autonomous agents. Simplicity is key.

📄

No Pagination

Unbounded responses overwhelm agent context windows. Cursor-based pagination solves this.

🔄

Not Idempotent

Agents retry on failure. Without idempotency, retries create duplicates.

🔍

Not Discoverable

If agents can't find your API in a network, it doesn't exist to them.
