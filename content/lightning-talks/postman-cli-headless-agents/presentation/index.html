A Script Can Run the CLI. It Can't Judge the Diff.

Lint, generate, run — any CI step can call those, every time, the same way. The one thing that needs an agent is deciding whether this specific change is even worth the CLI's time. Watch it happen next, in a real PR, on a real repo.

A Pull Request Opens

CI starts the run — no one prompts it.

→

The Agent Reads the Diff

Not a script: judges whether the change is the kind a consumer could break on.

→

The CLI, Only If Warranted

Nothing risky → stops here. Risky → context-graph ask.

→

A Comment Graded to the Evidence

"Nobody reads that field" reads nothing like "three teams do" — it writes the one that's true.

agents/headless-pr-agent.md
# A script already runs lint/generate/run every time.
# Your job starts where a fixed script can't go:

1. Read the diff. Judge it — don't just diff it.
2. Nothing risky changed? Say so. Stop. Spend nothing.
3. Something risky did? context-graph ask --wait
   "who calls this endpoint, who owns them?"
   Read the evidence — decide if it applies.
4. Run the EXISTING collection against a fresh mock
   self-consistency, before blaming anyone else
5. One PR comment, graded to what you found.
.github/workflows/headless-agent.yml
on:
  pull_request:
    paths: ["**/openapi.yaml"]

jobs:
  review:
    steps:
      - run: postman login --with-api-key ...
      - run: |
          claude -p "$(cat agents/headless-pr-agent.md)" \
            --dangerously-skip-permissions
