The shift · Orbit by Postman

Describe the outcome. Get the interfaces.

search
In: a sentence about what you need to do.
Out: callable endpoints — method, URL, and an evaluation of what each one does and what it won't.
evaluateGuide
→
integrate
In: the task + the endpoints you picked.
Out: one brief — FIT, AUTH, BASE URL, STEPS, GOTCHAS. Parameters, bodies, response shapes, order.
taskBrief
"Find and evaluate public API endpoints that match a plain-language goal. … Review `evaluateGuide` to pick the best fit, then pass each chosen result's `id` and `resourceType` (as `type`) to `integrate`. No authentication required." — Orbit MCP server, the search tool description, verbatim
Orbit doesn't just wrap its API. The tool description carries the workflow — so the agent runs both steps because Orbit told it how, not because I did.
